# Empty React Project

Minimal React starter scaffolded with Vite.

Run locally:

```bash
npm install
npm run dev
```

Builder.io scaffold

I couldn't run external CLI commands from this environment. To generate the Builder page locally using the command you provided, run (replace `YOUR_SPACE_ID`):

```bash
npm run builder:code
# or run directly
npx "@builder.io/dev-tools@latest" code --url "https://builder.io/fiddle/02481875825947f98514d68d41c50dde?fromFigma=true" --spaceId "YOUR_SPACE_ID"
```

After running the Builder command, refresh the local dev server.
