Place asset images here so the Hero component can load them:

- `hero-art.png` — the side illustration (the large image you pasted)
- `hero-bg.png` — the background gradient/texture image used behind the card

Save both files to `src/assets/` (case-sensitive path). After placing them, restart the dev server if it's running.

Example path:

```
src/assets/hero-art.png
src/assets/hero-bg.png
```
